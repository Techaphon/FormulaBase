1. ภาพรวมระบบ

Formula Base เป็นเว็บสำหรับจัดการสูตร วัตถุดิบ แผนผลิต การทำงานของพนักงาน และประวัติการผลิต โดยแยกบทบาท CEO, QC, PC และ Worker และรองรับภาษาไทยกับอังกฤษ

เทคโนโลยี: Java / Spring Boot เป็น backend, Thymeleaf สร้าง HTML, CSS และ JavaScript ดูแลหน้าเว็บ, Spring Data JPA และ Hibernate ติดต่อข้อมูล, PostgreSQL บน Supabase เก็บข้อมูล production, H2 ใช้ทดลองในเครื่อง, Flyway จัดการ migration และ Cloud Run รันแอปใน container

เส้นทางข้อมูล: ผู้ใช้กดปุ่ม → Controller รับคำขอ → Service ตรวจสิทธิ์และกฎธุรกิจ → Repository อ่านหรือบันทึก → ฐานข้อมูล → Controller ส่งข้อมูลให้ Thymeleaf แสดงผล

ตัวอย่าง: Worker กดเริ่มขั้นตอน → WorkerController รับ POST → ProductionExecutionService ตรวจผู้รับผิดชอบ ลำดับและสถานะ → บันทึกผล → หน้าเว็บแสดงสถานะใหม่

2. บทบาทและ Workflow

QC: จัดการวัตถุดิบและสูตร กรอกคำสั่งผลิตภาษาไทยและอังกฤษ ส่งสูตรและตรวจรายการคุณภาพตามสิทธิ์

CEO: ดูภาพรวม ตรวจและอนุมัติสูตร ดูความคืบหน้าการผลิต และจัดการผู้ใช้ตามสิทธิ์ การดูหน้างานไม่เท่ากับทำงานผลิตแทน Worker

PC: จัดการแผนรายเดือน เพิ่มงาน กำหนดวัน มอบหมายพนักงาน และจัดการแผนตามสถานะและเงื่อนไข

Worker: ดูงานที่ได้รับมอบหมายตามเงื่อนไขวันและสถานะ เริ่มงาน ทำขั้นตอนตามลำดับ และบันทึกผลผลิต

ลำดับหลัก: QC สร้างและส่งสูตร → CEO ตรวจสูตร → PC วางแผนและมอบหมาย → Worker ผลิต → ผู้มีสิทธิ์ตรวจความคืบหน้า คุณภาพและประวัติ

สิทธิ์จริงยังขึ้นอยู่กับสถานะและเงื่อนไขในโค้ดแต่ละกรณี ไม่ควรสรุปจากชื่อ role อย่างเดียว

ไฟล์ / โฟลเดอร์หน้าที่

ตัวอย่างการคำนวณ

จำนวนเผื่อ = ปัดขึ้น(เป้าหมาย × เปอร์เซ็นต์เผื่อ ÷ 100)
เป้าหมาย 101 ชิ้น เผื่อ 5% = 5.05 ปัดขึ้นเป็น 6 → วางแผนผลิต 107 ชิ้น

สินค้าดี = จำนวนผลิตจริงทั้งหมด − จำนวนสินค้าเสีย เช่น ผลิต 100 เสีย 1 จึงมีสินค้าดี 99 ชิ้น ระบบใช้ BigDecimal สำหรับคำนวณทศนิยมและควบคุมการปัดเศษ

10. Configuration และภาษา

application.properties กำหนดค่ากลาง; application-dev.properties ตั้งค่าทดลอง H2; application-prod.properties ใช้ PostgreSQL และ Flyway โดยรับ DB_URL, DB_USERNAME และ DB_PASSWORD จาก environment

messages.properties, messages_th.properties และ messages_en.properties เก็บข้อความ UI ตามภาษา ส่วนคำสั่งผลิตสองภาษาเป็นข้อมูลที่ผู้สร้างสูตรกรอก ไม่ได้แปลอัตโนมัติ

H2 แบบชั่วคราวตาม README จะเริ่มใหม่เมื่อปิดแอป ส่วน production ใช้ฐานข้อมูล PostgreSQL แยกต่างหาก

14. ตัวอย่างคำถามอาจารย์

ทำไมแยก Controller, Service และ Repository?

Controller รับคำขอ Service ตรวจและดำเนินกฎธุรกิจ Repository ติดต่อข้อมูล ทำให้แต่ละส่วนอ่าน ทดสอบ และแก้ไขได้ง่ายขึ้น

ซ่อนปุ่มแล้วปลอดภัยหรือยัง?

ยังไม่พอ เพราะส่ง request ตรงได้ ระบบจึงตรวจสิทธิ์ที่ URL และตรวจเงื่อนไขใน service ด้วย

ทำไมต้องมีขั้นตอนต้นแบบและขั้นตอนที่ทำจริง?

ขั้นตอนต้นแบบอยู่ในสูตร ส่วนผลการทำจริงอยู่ในงานแต่ละงาน ทำให้สูตรเดียวใช้หลายงานและเก็บผลแยกกันได้

ทำไมต้องมี revision ของสูตร?

เพื่อเก็บรุ่นเก่าให้ตรวจสอบย้อนหลัง และระบุได้ว่างานผลิตใช้สูตรรุ่นใด

ทำไมใช้ BigDecimal และปัดขึ้น?

เพื่อควบคุมการคำนวณทศนิยมและการปัดเศษให้ชัดเจน จำนวนเผื่อถูกปัดขึ้นเป็นจำนวนสินค้าทั้งชิ้น

ทำไมใช้ Flyway?

เพื่อจัดการการเปลี่ยน schema เป็นเวอร์ชันและรันตามลำดับที่ตรวจสอบได้

รหัสผ่านเก็บอย่างไร?

ใช้ BCrypt hash ก่อนเก็บ และตรวจรหัสที่ผู้ใช้กรอกกับ hash ไม่เก็บรหัสจริงเป็นข้อความธรรมดา

ทำไมกำหนดเวลาเป็น Asia/Bangkok?

เพื่อให้วันผลิตและงานรายวันตรงกับวันทำงานในไทย แม้เซิร์ฟเวอร์ใช้เขตเวลาอื่น

จำนวนผลิตทั้งหมดกับสินค้าดีต่างกันอย่างไร?

จำนวนผลิตทั้งหมดรวมสินค้าดีและเสีย ส่วนสินค้าดีเท่ากับจำนวนทั้งหมดลบจำนวนเสีย

บัญชีถูกนำออกแล้วประวัติหายหรือไม่?

ระบบออกแบบให้เก็บข้อมูลที่จำเป็นต่อประวัติ และตรวจงานค้างหรือจัดการส่งต่องานตามเงื่อนไขก่อนนำบัญชีออก

ระบบแปลคำสั่งผลิตอัตโนมัติหรือไม่?

ไม่ ผู้สร้างสูตรกรอกคำสั่งไทยและอังกฤษ ระบบเลือกแสดงตามภาษาที่ใช้

ทำไมข้อมูลเดโมหายหลังปิดแอป?

คำสั่งใน README ใช้ H2 แบบ in-memory เพื่อเริ่มทดลองใหม่ได้ง่าย ข้อมูลจึงหายเมื่อปิดแอป ไม่ใช่ลักษณะของฐานข้อมูล production

15. ข้อจำกัดที่ควรตอบตามจริง

  • ชุดทดสอบไม่ได้รับประกันว่าไม่มีบั๊กทุกกรณี และบางการทดสอบต้องมี PostgreSQL
  • บัญชีเดโมและ H2 ใช้สำหรับทดลอง ต้องไม่ใช้ข้อมูลรับรองเดโมเป็น production
  • สิทธิ์จริงขึ้นกับ role สถานะ และเงื่อนไขใน service
  • ผลตรวจหรือ deployment ในอดีตไม่ยืนยันสถานะปัจจุบันโดยอัตโนมัติ
  • ก่อนส่ง repository ต้องกรอกข้อมูลสมาชิก ตรวจข้อมูลลับและสิทธิ์เข้าถึงให้ครบ
